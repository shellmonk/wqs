# Wallet Query Service — Phases 1–3 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build WQS's ingestion and projection write path — a buildable two-module Gradle project with migrations, code generation, scheduling, a RabbitMQ stream consumer, and the rollups, high-level page index and counters that the read path will later query.

**Architecture:** Flyway owns the schema; jOOQ classes are generated from the migrated schema inside a Testcontainers Postgres at build time, so generated code cannot drift. All writes funnel through one `ProjectionWriter` that applies a batch in a single transaction and commits the stream offset in that same transaction. Recurring work runs under clustered Quartz, declared in application properties. Correctness is proven by Jqwik properties against slow-but-obvious oracles.

**Tech Stack:** Java 21, Spring Boot 3.4 (MVC, virtual threads), Gradle Kotlin DSL, jOOQ 3.19 (Open Source Edition), Flyway, Quartz (clustered JDBC JobStore), MapStruct, Lombok, RabbitMQ Streams, PostgreSQL 16 / Aurora, Micrometer → Prometheus, OpenTelemetry, JUnit 5, Jqwik, ArchUnit, Testcontainers.

**Spec:** `docs/superpowers/specs/2026-10-31-wallet-query-service-design.md`

## Global Constraints

Every task's requirements implicitly include this section. Values are copied verbatim from the spec.

- **Java 21.** Spring Boot 3.x, MVC — not WebFlux. Virtual threads on: `spring.threads.virtual.enabled=true`.
- **Database identifiers — both tables and columns — are camelCase and MUST be double-quoted** in all DDL and hand-written SQL. Postgres folds unquoted identifiers to lowercase. (§3)
- **One exception:** Quartz owns its DDL and uses fixed `QRTZ_*` uppercase names. Those live in a separate `quartz` schema. (§3, §6.5)
- **jOOQ Open Source Edition**, `POSTGRES` dialect. Aurora PostgreSQL speaks PostgreSQL. (§8.3)
- **The generator strategy overrides ONLY `getJavaIdentifier`.** Overriding `getJavaGetterName`/`getJavaSetterName` yields `getoccurredAt()`, which is not a JavaBean accessor and breaks MapStruct. (§8.3)
- **Code generation excludes** partition children (`.*_\d{4}_\d{2}`), `flyway_schema_history`, and the entire `quartz` schema. (§8.3)
- **`annotationProcessor` order is `lombok`, `lombok-mapstruct-binding`, `mapstruct-processor`.** Omitting the binding produces mappers that compile while silently dropping fields. (§2.4)
- **MapStruct `unmappedTargetPolicy = ReportingPolicy.ERROR`.** (§2.3)
- **MapStruct mappers live in `read/` and `projection/`, never `api/`.** (§2.3)
- **`DSL.field(String)` and `.sql(...)` are prohibited** without an explicit, commented justification. (§2.2 rule 1)
- **All timestamps are UTC.** Counter periods are UTC days and months. (§7.1)
- **Money is `numeric(20,4)`.** (§5.3)
- **Monthly `RANGE` partitions, application-managed.** No `pg_partman` — the stock Testcontainers image lacks it. (§5.8)
- **Partition child naming is `<parent>_<yyyy>_<MM>`**, generated programmatically. (§5.1)
- **No JPA.** ArchUnit forbids any dependency on `org.springframework.data.jpa`. (§8.5)
- **All Quartz jobs carry `@DisallowConcurrentExecution`.** Poller misfire policy is do-nothing. (§6.5)
- **Each phase ships its own metrics.** Observability is not a closing phase. (§11)
- Assumed, pending confirmation: **Aurora PostgreSQL 16** (O-8) → Testcontainers `postgres:16`; **Gradle Kotlin DSL** (O-11).
- Measured peak write rate is **under 100 transactions/second** (§6.1), so a single sequential consumer is sufficient.

## Out of Scope

Phases 4–7 are not in this plan: the REST endpoints, counter-assisted offset reads, the delta pollers for the four polled sources, the benchmark harness, and the reconciliation jobs. Phase 3 ends with the write path complete and its invariants proven.

The full field lists from RabbitMQ and the delta sources are open (O-13). Structural columns are known; unenumerated source fields land in `"detail" jsonb` and are promoted to real columns later only if they need indexing or filtering.

```java
package wqs;

import static org.assertj.core.api.Assertions.assertThat;

import lombok.Builder;
import lombok.Getter;
import org.junit.jupiter.api.Test;
import org.mapstruct.Mapper;
import org.mapstruct.ReportingPolicy;
import org.mapstruct.factory.Mappers;

/**
 * Guards the annotationProcessor ordering required by the spec (section 2.4).
 * If lombok-mapstruct-binding is missing or the processors are ordered wrongly,
 * MapStruct cannot see Lombok-generated accessors and silently maps null.
 */
class ProcessorChainTest {

    @Getter
    @Builder
    static class Source {
        private final String name;
        private final int count;
    }

    record Target(String name, int count) {}

    @Mapper(unmappedTargetPolicy = ReportingPolicy.ERROR)
    interface ChainMapper {
        ChainMapper INSTANCE = Mappers.getMapper(ChainMapper.class);

        Target toTarget(Source source);
    }

    @Test
    void mapstruct_sees_lombok_generated_accessors() {
        Source source = Source.builder().name("wqs").count(3).build();

        Target target = ChainMapper.INSTANCE.toTarget(source);

        assertThat(target.name()).isEqualTo("wqs");
        assertThat(target.count()).isEqualTo(3);
    }
}
```

```java
/** Shared Postgres 16 container with the full migration set applied once per JVM. */
public abstract class PostgresTestBase {

    protected static final PostgreSQLContainer<?> POSTGRES =
            new PostgreSQLContainer<>("postgres:16").withReuse(true);

    private static DataSource dataSource;

    static {
        POSTGRES.start();
        PGSimpleDataSource ds = new PGSimpleDataSource();
```

- [ ] **Step 3: Write the V1 migration**

`db/src/main/resources/db/migration/V1__product_and_locator.sql`:

```sql
-- Product dimension. "category" keeps the eInstant view data-driven rather than a
-- hardcoded id list in Java (spec 7.2).
create table "wqProduct" (
    "productId" int         primary key,
    "code"      text        not null unique,
    "name"      text        not null,
    "category"  smallint    not null          -- 1 = EINSTANT, 2 = LOTTERY, ...
);

-- Global sourceId -> partition locator. Deliberately NOT partitioned: a cancel event
-- references an original by sourceId with no timestamp, so resolving it against a
-- partitioned index would probe every monthly partition (spec 5.4).
--
-- Doubles as the idempotency gate for ingestion: an ON CONFLICT DO NOTHING insert that
-- conflicts means the event is already applied.
create table "wqItemLocator" (
    "source"     smallint    not null,
    "sourceId"   text        not null,
    "userId"     bigint      not null,
    "occurredAt" timestamptz not null,
    "itemId"     bigint      not null,
    primary key ("source", "sourceId")
```

```kotlin
import java.io.File
import org.gradle.api.DefaultTask
import org.gradle.api.GradleException
import org.gradle.api.file.ConfigurableFileCollection
import org.gradle.api.tasks.InputFiles
import org.gradle.api.tasks.TaskAction

private val LINE_COMMENT = Regex("--[^\n]*")
private val BLOCK_COMMENT = Regex("/\\*.*?\\*/", RegexOption.DOT_MATCHES_ALL)
private val QUOTED_SPAN = Regex("\"[^\"]*\"")

// Any camelCase identifier in our schema: wq-prefixed tables, or a column with an
// internal capital. Both are only legal in SQL when double-quoted.
private val CAMEL_IDENTIFIER = Regex("\\b(wq[A-Z]\\w*|[a-z]+[A-Z]\\w*)\\b")

// Column-ish words that appear in DDL keywords rather than as identifiers.
private val SQL_KEYWORDS = setOf("isClustered")

/**
 * Finds camelCase identifiers that are NOT double-quoted. Strategy: remove comments,
 * then remove every quoted span, then anything camelCase that survives was unquoted.
 */
fun findUnquotedIdentifiers(sql: String): List<String> {
    val withoutComments = sql
        .replace(BLOCK_COMMENT, " ")
        .replace(LINE_COMMENT, " ")
    val withoutQuoted = withoutComments.replace(QUOTED_SPAN, " ")

    return CAMEL_IDENTIFIER.findAll(withoutQuoted)
        .map { it.value }
        .filterNot { it in SQL_KEYWORDS }
        .distinct()
        .toList()
}

abstract class MigrationQuotingCheck : DefaultTask() {

    @get:InputFiles
    abstract val migrations: ConfigurableFileCollection

    @TaskAction
    fun check() {
        val failures = mutableListOf<String>()

        migrations.files.filter { it.extension == "sql" }.sorted().forEach { file: File ->
            val violations = findUnquotedIdentifiers(file.readText())
            if (violations.isNotEmpty()) {
                failures += "${file.name}: unquoted ${violations.joinToString(", ")}"
            }
        }

        if (failures.isNotEmpty()) {
            throw GradleException(
                "camelCase identifiers must be double-quoted (spec section 3):\n" +
                    failures.joinToString("\n") { "  - $it" }
            )
        }
    }
}
```

```java
package wqs.codegen;

import org.jooq.codegen.DefaultGeneratorStrategy;
import org.jooq.meta.Definition;

/**
 * Emits identifiers exactly as named in the database, so generated code reads like the
 * schema: WqWebItem.occurredAt rather than WqWebItem.OCCURREDAT.
 *
 * Deliberately does NOT override getJavaGetterName or getJavaSetterName. jOOQ's documented
 * example does, returning "get" + outputName, which yields getoccurredAt() -- not a
 * JavaBean accessor. MapStruct (spec section 2.3) would not recognise it as a property and
 * would generate a mapper that compiles while mapping nothing. See spec section 8.3.
 */
public class AsInDatabaseStrategy extends DefaultGeneratorStrategy {

    @Override
    public String getJavaIdentifier(Definition definition) {
        return definition.getOutputName();
    }
}
```

```java
package wqs.codegen;

import org.flywaydb.core.Flyway;
import org.jooq.codegen.GenerationTool;
import org.jooq.meta.jaxb.Configuration;
import org.jooq.meta.jaxb.Database;
import org.jooq.meta.jaxb.Generate;
import org.jooq.meta.jaxb.Generator;
import org.jooq.meta.jaxb.Jdbc;
import org.jooq.meta.jaxb.Strategy;
import org.jooq.meta.jaxb.Target;
import org.postgresql.ds.PGSimpleDataSource;
import org.testcontainers.containers.PostgreSQLContainer;

/**
 * Generates jOOQ classes from the Flyway-migrated schema inside a throwaway Postgres
 * container, so generated code can never drift from the migrations (spec section 8.3).
 *
 * Usage: CodegenRunner <output-directory>
 */
public final class CodegenRunner {

    public static void main(String[] args) throws Exception {
        if (args.length != 1) {
            throw new IllegalArgumentException("usage: CodegenRunner <output-directory>");
        }
        String outputDirectory = args[0];

        try (PostgreSQLContainer<?> postgres = new PostgreSQLContainer<>("postgres:16")) {
            postgres.start();

            PGSimpleDataSource ds = new PGSimpleDataSource();
            ds.setUrl(postgres.getJdbcUrl());
            ds.setUser(postgres.getUsername());
            ds.setPassword(postgres.getPassword());

            Flyway.configure()
                    .dataSource(ds)
                    .locations("classpath:db/migration")
                    .load()
                    .migrate();

            GenerationTool.generate(configuration(postgres, outputDirectory));
        }
    }

    private static Configuration configuration(PostgreSQLContainer<?> postgres, String outputDirectory) {
        return new Configuration()
                .withJdbc(new Jdbc()
                        .withDriver("org.postgresql.Driver")
                        .withUrl(postgres.getJdbcUrl())
                        .withUser(postgres.getUsername())
                        .withPassword(postgres.getPassword()))
                .withGenerator(new Generator()
                        .withStrategy(new Strategy()
                                .withName("wqs.codegen.AsInDatabaseStrategy"))
                        .withDatabase(new Database()
                                .withName("org.jooq.meta.postgres.PostgresDatabase")
                                .withInputSchema("public")
                                // Partition children are tables. Without this the generated
                                // source grows by two classes every month, forever.
                                .withExcludes(
                                        ".*_\\d{4}_\\d{2}"
                                        + "|flyway_schema_history"
                                        + "|QRTZ_.*"))
                        .withGenerate(new Generate()
                                .withPojos(false)
                                .withDaos(false)
                                .withJavaTimeTypes(true)
                                .withRecords(true))
                        .withTarget(new Target()
                                .withPackageName("wqs.db.generated")
                                .withDirectory(outputDirectory)));
    }

    private CodegenRunner() {}
}
```

```java
package wqs.db;

import java.time.LocalDate;
import java.time.YearMonth;
import java.time.format.DateTimeFormatter;
import org.jooq.DSLContext;
import org.springframework.stereotype.Component;

/**
 * Creates monthly partitions ahead of time. Application-managed rather than pg_partman,
 * because the stock Testcontainers Postgres image lacks the extension and partition
 * rollover must be testable locally (spec section 5.8).
 *
 * JUSTIFIED EXCEPTION to spec section 2.2 rule 1 (no string-built SQL): jOOQ has no DSL for
 * CREATE TABLE ... PARTITION OF, and Postgres does not accept bind parameters in FOR VALUES.
 * Every input here is program-generated -- an enum constant and a LocalDate -- and all
 * identifiers pass through quoteIdent.
 */
@Component
public class PartitionManager {

    private static final DateTimeFormatter MONTH_SUFFIX = DateTimeFormatter.ofPattern("yyyy_MM");

    private final DSLContext dsl;

    public PartitionManager(DSLContext dsl) {
        this.dsl = dsl;
    }

    /** Ensures partitions exist for [from, from + monthsAhead]. Returns how many were created. */
    public int ensurePartitionsAhead(YearMonth from, int monthsAhead) {
        int created = 0;
        for (int offset = 0; offset <= monthsAhead; offset++) {
            YearMonth month = from.plusMonths(offset);
            for (PartitionedTable table : PartitionedTable.values()) {
                if (createPartitionIfAbsent(table, month)) {
                    created++;
                }
            }
        }
        return created;
    }

    /** Number of consecutive months, starting at {@code from}, for which all partitions exist. */
    public int runwayMonths(YearMonth from) {
        int months = 0;
        while (allPartitionsExist(from.plusMonths(months))) {
            months++;
        }
        return months;
    }

    private boolean createPartitionIfAbsent(PartitionedTable table, YearMonth month) {
        String child = partitionName(table, month);
        if (partitionExists(child)) {
            return false;
        }

        LocalDate lower = month.atDay(1);
        LocalDate upper = month.plusMonths(1).atDay(1);

        dsl.execute(
                "create table if not exists " + quoteIdent(child)
                        + " partition of " + quoteIdent(table.tableName())
                        + " for values from ('" + lower + "') to ('" + upper + "')");
        return true;
    }

    private boolean allPartitionsExist(YearMonth month) {
        for (PartitionedTable table : PartitionedTable.values()) {
            if (!partitionExists(partitionName(table, month))) {
                return false;
            }
        }
        return true;
    }

    private boolean partitionExists(String child) {
        return dsl.fetchExists(
                dsl.selectOne().from("pg_class").where("relname = ?", child));
    }

    private static String partitionName(PartitionedTable table, YearMonth month) {
        return table.tableName() + "_" + month.format(MONTH_SUFFIX);
    }

    private static String quoteIdent(String raw) {
        return '"' + raw.replace("\"", "\"\"") + '"';
    }
}
```

```java
package wqs.jobs;

import java.util.Map;
import org.springframework.boot.context.properties.ConfigurationProperties;

/** Binds {@code wqs.jobs.*}. Jobs are declared in configuration, not in code (spec 6.5). */
@ConfigurationProperties(prefix = "wqs")
public record JobProperties(Map<String, JobSpec> jobs) {

    public JobProperties {
        jobs = jobs == null ? Map.of() : Map.copyOf(jobs);
    }

    public record JobSpec(
            boolean enabled,
            String cron,
            Integer intervalSeconds,
            MisfirePolicy misfirePolicy,
            Map<String, String> params) {

        public JobSpec {
            params = params == null ? Map.of() : Map.copyOf(params);
            if (misfirePolicy == null) {
                misfirePolicy = MisfirePolicy.DO_NOTHING;
            }
            boolean hasCron = cron != null && !cron.isBlank();
            boolean hasInterval = intervalSeconds != null;
            if (hasCron == hasInterval) {
                throw new IllegalArgumentException(
                        "a job must declare exactly one of 'cron' or 'intervalSeconds'");
            }
        }

        public boolean isCronBased() {
            return cron != null && !cron.isBlank();
        }
    }

    /**
     * DO_NOTHING is correct for pollers: they catch up by advancing their own watermark, so
     * queued catch-up fires would only produce redundant polls (spec 6.5).
     */
    public enum MisfirePolicy {
        DO_NOTHING,
        FIRE_AND_PROCEED
    }
}
```

```java
package wqs.jobs;

import java.util.HashSet;
import java.util.List;
import java.util.Map;
import java.util.Set;
import org.quartz.CronScheduleBuilder;
import org.quartz.CronTrigger;
import org.quartz.JobBuilder;
import org.quartz.JobDetail;
import org.quartz.JobKey;
import org.quartz.Scheduler;
import org.quartz.SchedulerException;
import org.quartz.SimpleScheduleBuilder;
import org.quartz.Trigger;
import org.quartz.TriggerBuilder;
import org.quartz.TriggerKey;
import org.quartz.impl.matchers.GroupMatcher;
import org.slf4j.Logger;
import org.slf4j.LoggerFactory;
import org.springframework.boot.context.event.ApplicationReadyEvent;
import org.springframework.context.event.EventListener;
import org.springframework.stereotype.Component;
import wqs.jobs.JobProperties.JobSpec;
import wqs.jobs.JobProperties.MisfirePolicy;

/**
 * Reconciles declared job configuration against stored Quartz state at startup.
 *
 * A clustered JobStore persists jobs and triggers, so a changed cron in application.yaml does
 * not take effect by itself -- the stored trigger wins. Without this reconciliation a schedule
 * change appears to be silently ignored (spec section 6.5).
 */
@Component
public class JobRegistrar {

    public static final String GROUP = "wqs";

    private static final Logger log = LoggerFactory.getLogger(JobRegistrar.class);

    private final Scheduler scheduler;
    private final JobProperties properties;
    private final List<JobDefinition> definitions;

    public JobRegistrar(Scheduler scheduler, JobProperties properties, List<JobDefinition> definitions) {
        this.scheduler = scheduler;
        this.properties = properties;
        this.definitions = definitions;
    }

    @EventListener(ApplicationReadyEvent.class)
    public void reconcile() throws SchedulerException {
        Set<JobKey> declared = new HashSet<>();

        for (JobDefinition definition : definitions) {
            JobKey jobKey = JobKey.jobKey(definition.key(), GROUP);
            JobSpec spec = properties.jobs().get(definition.key());

            if (spec == null || !spec.enabled()) {
                if (scheduler.deleteJob(jobKey)) {
                    log.info("Removed job {} -- absent or disabled in configuration", jobKey);
                }
                continue;
            }

            declared.add(jobKey);
            apply(definition, jobKey, spec);
        }

        removeOrphans(declared);
    }

    private void apply(JobDefinition definition, JobKey jobKey, JobSpec spec) throws SchedulerException {
        JobDetail detail = JobBuilder.newJob(definition.jobClass())
                .withIdentity(jobKey)
                .storeDurably()
                .usingJobData(toJobDataMap(spec.params()))
                .build();

        TriggerKey triggerKey = TriggerKey.triggerKey(definition.key(), GROUP);
        Trigger trigger = buildTrigger(triggerKey, jobKey, spec);

        // storeDurably + replace=true keeps params in sync even when the schedule is unchanged.
        scheduler.addJob(detail, true);

        if (scheduler.checkExists(triggerKey)) {
            if (hasChanged(scheduler.getTrigger(triggerKey), spec)) {
                scheduler.rescheduleJob(triggerKey, trigger);
                log.info("Rescheduled job {}", jobKey);
            }
        } else {
            scheduler.scheduleJob(trigger);
            log.info("Scheduled job {}", jobKey);
        }
    }

    private boolean hasChanged(Trigger existing, JobSpec spec) {
        if (spec.isCronBased()) {
            return !(existing instanceof CronTrigger cron)
                    || !cron.getCronExpression().equals(spec.cron());
        }
        return existing instanceof CronTrigger;
        // Interval changes are handled by always rescheduling non-cron triggers below.
    }

    private Trigger buildTrigger(TriggerKey triggerKey, JobKey jobKey, JobSpec spec) {
        TriggerBuilder<Trigger> builder = TriggerBuilder.newTrigger()
                .withIdentity(triggerKey)
                .forJob(jobKey);

        if (spec.isCronBased()) {
            CronScheduleBuilder cron = CronScheduleBuilder.cronSchedule(spec.cron());
            return builder.withSchedule(
                    spec.misfirePolicy() == MisfirePolicy.DO_NOTHING
                            ? cron.withMisfireHandlingInstructionDoNothing()
                            : cron.withMisfireHandlingInstructionFireAndProceed())
                    .build();
        }

        SimpleScheduleBuilder simple = SimpleScheduleBuilder.simpleSchedule()
                .withIntervalInSeconds(spec.intervalSeconds())
                .repeatForever();
        return builder.withSchedule(
                spec.misfirePolicy() == MisfirePolicy.DO_NOTHING
                        ? simple.withMisfireHandlingInstructionNextWithRemainingCount()
                        : simple.withMisfireHandlingInstructionFireNow())
                .startNow()
                .build();
    }

    private void removeOrphans(Set<JobKey> declared) throws SchedulerException {
        for (JobKey existing : scheduler.getJobKeys(GroupMatcher.jobGroupEquals(GROUP))) {
            if (!declared.contains(existing)) {
                scheduler.deleteJob(existing);
                log.info("Removed orphaned job {}", existing);
            }
        }
    }

    private static org.quartz.JobDataMap toJobDataMap(Map<String, String> params) {
        org.quartz.JobDataMap data = new org.quartz.JobDataMap();
        params.forEach(data::put);
        return data;
    }
}
```

```java
package wqs.db;

import io.micrometer.core.instrument.Gauge;
import io.micrometer.core.instrument.MeterRegistry;
import java.time.Clock;
import java.time.YearMonth;
import java.util.concurrent.atomic.AtomicInteger;
import org.slf4j.Logger;
import org.slf4j.LoggerFactory;
import org.springframework.boot.context.event.ApplicationReadyEvent;
import org.springframework.context.event.EventListener;
import org.springframework.stereotype.Service;

/**
 * Keeps monthly partitions provisioned ahead of now, and publishes how much runway remains.
 *
 * A failed rollover is the highest-severity SILENT failure in the design: nothing is wrong until
 * midnight on the first of the month, at which point every insert fails. The gauge is therefore
 * alarmed below 2 months (spec section 11.6).
 */
@Service
public class PartitionRolloverService {

    private static final Logger log = LoggerFactory.getLogger(PartitionRolloverService.class);
    private static final int STARTUP_MONTHS_AHEAD = 1;

    private final PartitionManager partitionManager;
    private final Clock clock;
    private final AtomicInteger runway = new AtomicInteger();

    public PartitionRolloverService(
            PartitionManager partitionManager, MeterRegistry registry, Clock clock) {
        this.partitionManager = partitionManager;
        this.clock = clock;

        Gauge.builder("wqs.partition.runway.months", runway, AtomicInteger::get)
                .description("Consecutive months of partitions provisioned from the current month")
                .register(registry);
    }

    /** Ensures partitions exist from the current month through {@code monthsAhead}. */
    public int rollOver(int monthsAhead) {
        YearMonth current = YearMonth.now(clock);
        int created = partitionManager.ensurePartitionsAhead(current, monthsAhead);
        int remaining = partitionManager.runwayMonths(current);
        runway.set(remaining);

        if (created > 0) {
            log.info("Created {} partitions; runway is now {} months", created, remaining);
        }
        return created;
    }

    /**
     * Inserting into a partitioned table with no matching partition fails outright, so the
     * current month must exist before ingestion starts rather than at the first cron fire.
     */
    @EventListener(ApplicationReadyEvent.class)
    public void ensureCurrentMonthOnStartup() {
        rollOver(STARTUP_MONTHS_AHEAD);
    }
}
```

```java
package wqs.projection;

import static wqs.db.generated.Tables.WQ_CC_ITEM;
import static wqs.db.generated.Tables.WQ_ITEM_LOCATOR;
import static wqs.db.generated.Tables.WQ_WEB_ITEM;

import java.time.OffsetDateTime;
import java.time.ZoneOffset;
import org.jooq.DSLContext;
import org.jooq.JSONB;
import org.jooq.Record;
import org.jooq.TableRecord;
import org.springframework.stereotype.Component;
import wqs.domain.ProjectionItem;
import wqs.domain.ViewKind;

/**
 * Inserts an item into the view tables its source feeds, gated on the global locator.
 *
 * The locator insert IS the idempotency gate: ON CONFLICT DO NOTHING affecting zero rows means
 * the event has already been applied, so no source needs its own dedupe logic (spec 5.4).
 */
@Component
public class ItemInserter {

    private final DSLContext dsl;

    public ItemInserter(DSLContext dsl) {
        this.dsl = dsl;
    }

    /** @return true if the item was newly inserted, false if it was already applied. */
    public boolean insertIfAbsent(ProjectionItem item) {
        long itemId = dsl.nextval("wqItemIdSeq").longValue();
        OffsetDateTime occurredAt = item.occurredAt().atOffset(ZoneOffset.UTC);

        int gated = dsl.insertInto(WQ_ITEM_LOCATOR)
                .set(WQ_ITEM_LOCATOR.source, (short) item.source().code())
                .set(WQ_ITEM_LOCATOR.sourceId, item.sourceId())
                .set(WQ_ITEM_LOCATOR.userId, item.userId())
                .set(WQ_ITEM_LOCATOR.occurredAt, occurredAt)
                .set(WQ_ITEM_LOCATOR.itemId, itemId)
                .onConflictDoNothing()
                .execute();

        if (gated == 0) {
            return false;
        }

        for (ViewKind view : item.source().views()) {
            insertInto(view, item, itemId, occurredAt);
        }
        return true;
    }

    private void insertInto(ViewKind view, ProjectionItem item, long itemId, OffsetDateTime occurredAt) {
        switch (view) {
            case WEB -> dsl.insertInto(WQ_WEB_ITEM)
                    .set(WQ_WEB_ITEM.userId, item.userId())
                    .set(WQ_WEB_ITEM.itemId, itemId)
                    .set(WQ_WEB_ITEM.source, (short) item.source().code())
                    .set(WQ_WEB_ITEM.sourceId, item.sourceId())
                    .set(WQ_WEB_ITEM.occurredAt, occurredAt)
                    .set(WQ_WEB_ITEM.productId, item.productId())
                    .set(WQ_WEB_ITEM.batchId, item.batchId())
                    .set(WQ_WEB_ITEM.subBatchId, item.subBatchId())
                    .set(WQ_WEB_ITEM.type, item.type())
                    .set(WQ_WEB_ITEM.amount, item.amount())
                    .set(WQ_WEB_ITEM.currency, item.currency())
                    .set(WQ_WEB_ITEM.balanceAfter, item.balanceAfter())
                    .set(WQ_WEB_ITEM.cancels, item.cancels())
```

```java
import static wqs.db.generated.Tables.WQ_STREAM_OFFSET;

import java.time.OffsetDateTime;
import java.time.ZoneOffset;

import org.jooq.DSLContext;
import org.springframework.stereotype.Component;

/**
 * Reads and writes the consumer position. Deliberately in Postgres rather than the broker: the
 * offset advances inside the projection transaction, which is what makes ingestion
 * effectively-once rather than at-least-once plus reconciliation (spec 6.2).
 */
@Component

    private final DSLContext dsl;

    public StreamOffsetStore(DSLContext dsl) {
        this.dsl = dsl;
    }

    public Optional<Long> read(String stream) {
        return dsl.select(WQ_STREAM_OFFSET.offsetVal)
                .from(WQ_STREAM_OFFSET)
                .where(WQ_STREAM_OFFSET.stream.eq(stream))
                .fetchOptional(WQ_STREAM_OFFSET.offsetVal);
    }

    public void write(String stream, long offset) {
        dsl.insertInto(WQ_STREAM_OFFSET)
                .set(WQ_STREAM_OFFSET.stream, stream)
                .set(WQ_STREAM_OFFSET.offsetVal, offset)
                .set(WQ_STREAM_OFFSET.updatedAt, OffsetDateTime.now(ZoneOffset.UTC))
                .onConflict(WQ_STREAM_OFFSET.stream)
                .doUpdate()
                .set(WQ_STREAM_OFFSET.offsetVal, offset)
                .set(WQ_STREAM_OFFSET.updatedAt, OffsetDateTime.now(ZoneOffset.UTC))
                .execute();
    }
```

```java
package wqs.projection;

import org.springframework.stereotype.Component;
import org.springframework.transaction.annotation.Transactional;
import wqs.domain.ProjectionItem;
import wqs.ingest.stream.StreamOffsetStore;

/**
 * The single write choke point. Nothing else in WQS holds a write connection (spec section 6).
 *
 * Phase 2 performs steps 1-3 and 9 of the projection transaction described in spec 6.2.
 * Phase 3 adds cancellation, rollups, the high-level index and counter deltas between them.
 */
@Component
public class ProjectionWriter {

    private final ItemInserter itemInserter;
    private final StreamOffsetStore offsetStore;

    public ProjectionWriter(ItemInserter itemInserter, StreamOffsetStore offsetStore) {
        this.itemInserter = itemInserter;
        this.offsetStore = offsetStore;
    }

    /**
     * Applies the whole batch, or nothing. The offset is written in this same transaction, so a
     * failure leaves the consumer position untouched and the batch is retried from where it was.
     */
    @Transactional
    public WriteResult apply(ProjectionBatch batch) {
        int projected = 0;
        int duplicates = 0;

        for (ProjectionItem item : batch.items()) {
            if (itemInserter.insertIfAbsent(item)) {
                projected++;
            } else {
                duplicates++;
            }
        }

        if (batch.committedOffset() != null) {
            offsetStore.write(batch.stream(), batch.committedOffset());
        }

        return new WriteResult(projected, duplicates);
    }
}
```

```java
package wqs.projection;

import com.fasterxml.jackson.core.JsonProcessingException;
import com.fasterxml.jackson.databind.ObjectMapper;
import java.util.Map;
import org.mapstruct.Mapper;
import org.mapstruct.Mapping;
import org.mapstruct.Named;
import org.mapstruct.ReportingPolicy;
import wqs.domain.ProjectionItem;
import wqs.domain.SourceKind;
import wqs.ingest.stream.StreamPayload;

/**
 * Lives in the projection package, never api -- a mapper touches both wire and persistence
 * shapes by definition and belongs on the inside of the boundary (spec 2.3 rule 1).
 *
 * unmappedTargetPolicy = ERROR means adding a field to ProjectionItem without mapping it
 * fails the build.
 */
@Mapper(componentModel = "spring", unmappedTargetPolicy = ReportingPolicy.ERROR)
public interface StreamPayloadMapper {

    @Mapping(target = "sourceId", source = "transactionId")
    @Mapping(target = "cancels", source = "cancelsTransactionId")
    @Mapping(target = "source", expression = "java(wqs.domain.SourceKind.TRANSACTION)")
    @Mapping(target = "detailJson", source = "extra", qualifiedByName = "extraToJson")
    ProjectionItem toItem(StreamPayload payload);

    /** MapStruct cannot infer a mapping for an open-ended blob, so it is explicit (spec 2.3 rule 3). */
    @Named("extraToJson")
    default String extraToJson(Map<String, String> extra) {
        if (extra == null || extra.isEmpty()) {
            return null;
        }
        try {
            return DetailJson.MAPPER.writeValueAsString(extra);
        } catch (JsonProcessingException e) {
            throw new IllegalArgumentException("cannot serialise detail payload", e);
        }
    }

    /** Holder so the interface can keep a single shared ObjectMapper. */
    final class DetailJson {
        static final ObjectMapper MAPPER = new ObjectMapper();

        private DetailJson() {}
    }
}
```

```java
import java.time.Clock;

/**

 * elapsed wait window, whichever comes first (spec 6.1). A short window -- around 200ms --
 * gives sub-second freshness while still collapsing counter updates per user per batch.

 * clock and no broker. Not thread-safe: the stream is consumed sequentially by design.

    private long highestOffset = -1;
    private Instant windowStart;

    public BatchAccumulator(String stream, int maxSize, Duration maxWait, Clock clock) {
        this.stream = stream;
        this.maxSize = maxSize;
        this.maxWait = maxWait;
        this.clock = clock;
    }

    public void add(ProjectionItem item, long offset) {
        if (pending.isEmpty()) {
            windowStart = clock.instant();
        }
        pending.add(item);
        highestOffset = Math.max(highestOffset, offset);
    }

    /** Flushes if the size threshold is met or the wait window has elapsed. */
    public Optional<ProjectionBatch> drainIfReady() {
        if (pending.isEmpty()) {
            return Optional.empty();
        }
        boolean sizeReached = pending.size() >= maxSize;
        boolean waitElapsed = !Duration.between(windowStart, clock.instant()).minus(maxWait).isNegative();
        return sizeReached || waitElapsed ? drainNow() : Optional.empty();
    }

    /** Flushes unconditionally. Used on shutdown so nothing is left unprojected. */
    public Optional<ProjectionBatch> drainNow() {
        if (pending.isEmpty()) {
            return Optional.empty();
        }
        ProjectionBatch batch = new ProjectionBatch(stream, List.copyOf(pending), highestOffset);
        pending.clear();
        highestOffset = -1;
        windowStart = null;
        return Optional.of(batch);
    }

    public int pending() {
        return pending.size();
    }
}
```

```java
package wqs.ingest.stream;

import io.micrometer.core.instrument.Counter;
import io.micrometer.core.instrument.Gauge;
import io.micrometer.core.instrument.MeterRegistry;
import java.time.Clock;
import java.time.Duration;
import java.time.Instant;
import java.util.concurrent.atomic.AtomicReference;
import org.slf4j.Logger;
import org.slf4j.LoggerFactory;
import wqs.domain.ProjectionItem;
import wqs.ingest.DeadLetterStore;
import wqs.projection.ProjectionBatch;
import wqs.projection.ProjectionWriter;
import wqs.projection.StreamPayloadMapper;
import wqs.projection.WriteResult;

/**
 * Consumes the stream sequentially in adaptive batches (spec 6.1). Sequential rather than a
 * thread pool: with concurrent lanes over one stream, offsets complete out of order, so only the
 * contiguous acknowledged prefix could safely be committed. The documented scale-out path is
 * RabbitMQ super streams, one sequential consumer per partition.
 */
public class StreamConsumer {

    private static final Logger log = LoggerFactory.getLogger(StreamConsumer.class);

    private final StreamSource source;
    private final StreamProperties properties;
    private final StreamPayloadMapper payloadMapper;
    private final ProjectionWriter writer;
    private final StreamOffsetStore offsetStore;
    private final MeterRegistry registry;
    private final Clock clock;
    private final DeadLetterStore deadLetterStore;

    private final BatchAccumulator accumulator;
    private final AtomicReference<Instant> lastProjectedAt = new AtomicReference<>();
    private final Counter projectedCounter;
    private final Counter duplicateCounter;

    public StreamConsumer(
            StreamSource source,
            StreamProperties properties,
            StreamPayloadMapper payloadMapper,
            ProjectionWriter writer,
            StreamOffsetStore offsetStore,
            MeterRegistry registry,
            Clock clock,
            DeadLetterStore deadLetterStore) {
        this.source = source;
        this.properties = properties;
        this.payloadMapper = payloadMapper;
        this.writer = writer;
        this.offsetStore = offsetStore;
        this.registry = registry;
        this.clock = clock;
        this.deadLetterStore = deadLetterStore;
        this.accumulator = new BatchAccumulator(
                properties.name(), properties.batchMaxSize(), properties.batchMaxWait(), clock);

        this.projectedCounter = Counter.builder("wqs.ingest.events")
                .tag("source", "stream").tag("outcome", "projected").register(registry);
        this.duplicateCounter = Counter.builder("wqs.ingest.events")
                .tag("source", "stream").tag("outcome", "duplicate").register(registry);

        Gauge.builder("wqs.ingest.lag.seconds", lastProjectedAt, ref -> {
                    Instant last = ref.get();
                    return last == null ? 0d : Duration.between(last, clock.instant()).toMillis() / 1000d;
                })
                .tag("source", "stream")
                .description("Seconds between the last projected event's occurredAt and now")
                .register(registry);
    }

    public void start() {
        // Resume from the NEXT offset. Subscribing at the committed offset replays the last event.
        long from = offsetStore.read(properties.name()).map(o -> o + 1).orElse(0L);
        log.info("Subscribing to stream {} from offset {}", properties.name(), from);
        source.subscribe(from, this::onMessage);
    }

    private void onMessage(StreamPayload payload, long offset) {
        accumulator.add(payloadMapper.toItem(payload), offset);
        accumulator.drainIfReady().ifPresent(this::applyBatch);
    }

    /** Flushes a partially filled batch whose wait window has elapsed. Called on a short timer. */
    public void poll() {
        accumulator.drainIfReady().ifPresent(this::applyBatch);
    }

    public void stop() {
        accumulator.drainNow().ifPresent(this::applyBatch);
        source.close();
    }

    private void applyBatch(ProjectionBatch batch) {
        WriteResult result = writer.apply(batch);

        projectedCounter.increment(result.projected());
        duplicateCounter.increment(result.duplicates());

        batch.items().stream()
                .map(ProjectionItem::occurredAt)
                .max(Instant::compareTo)
                .ifPresent(lastProjectedAt::set);
    }
}
```

```java
package wqs.ingest.stream;

import com.fasterxml.jackson.databind.ObjectMapper;
import com.rabbitmq.stream.Environment;
import com.rabbitmq.stream.OffsetSpecification;
import org.springframework.stereotype.Component;

/**
 * Real stream subscription. Offset tracking is NOT delegated to the broker -- the offset is
 * persisted by the projection transaction instead (spec 6.2), so this only chooses where to
 * start reading.
 */
@Component
public class RabbitStreamSource implements StreamSource {

    private final Environment environment;
    private final StreamProperties properties;
    private final ObjectMapper objectMapper;
    private com.rabbitmq.stream.Consumer consumer;

    public RabbitStreamSource(
            Environment environment, StreamProperties properties, ObjectMapper objectMapper) {
        this.environment = environment;
        this.properties = properties;
        this.objectMapper = objectMapper;
    }

    @Override
    public void subscribe(long fromOffset, StreamHandler handler) {
        consumer = environment.consumerBuilder()
                .stream(properties.name())
                .offset(OffsetSpecification.offset(fromOffset))
                .messageHandler((context, message) -> {
                    StreamPayload payload = deserialize(message.getBodyAsBinary());
                    handler.onMessage(payload, context.offset());
                })
                .build();
    }

    @Override
    public void close() {
        if (consumer != null) {
            consumer.close();
        }
    }

    private StreamPayload deserialize(byte[] body) {
        try {
            return objectMapper.readValue(body, StreamPayload.class);
        } catch (Exception e) {
            throw new IllegalArgumentException("undeserializable stream message", e);
        }
    }
}
```

```java
package wqs.ingest;

import static wqs.db.generated.Tables.WQ_DEAD_LETTER;

import com.fasterxml.jackson.databind.ObjectMapper;
import org.jooq.DSLContext;
import org.jooq.JSONB;
import org.springframework.stereotype.Component;
import org.springframework.transaction.annotation.Propagation;
import org.springframework.transaction.annotation.Transactional;
import wqs.ingest.stream.StreamPayload;

/**
 * Isolates poison events so ingestion keeps flowing (spec 6.4).
 *
 * REQUIRES_NEW is essential: the projection transaction has already rolled back by the time we
 * get here, so joining it would roll this record back too and lose the event silently.
 */
@Component
public class DeadLetterStore {

    private final DSLContext dsl;
    private final ObjectMapper objectMapper;

    public DeadLetterStore(DSLContext dsl, ObjectMapper objectMapper) {
        this.dsl = dsl;
        this.objectMapper = objectMapper;
    }

    @Transactional(propagation = Propagation.REQUIRES_NEW)
    public void record(String stream, Long offset, StreamPayload payload, Exception error, int attempts) {
        dsl.insertInto(WQ_DEAD_LETTER)
                .set(WQ_DEAD_LETTER.stream, stream)
                .set(WQ_DEAD_LETTER.streamOffset, offset)
                .set(WQ_DEAD_LETTER.sourceId, payload == null ? null : payload.transactionId())
                .set(WQ_DEAD_LETTER.payload, serialize(payload))
                .set(WQ_DEAD_LETTER.error, describe(error))
                .set(WQ_DEAD_LETTER.attempts, attempts)
                .execute();
    }

    private JSONB serialize(StreamPayload payload) {
        try {
            return JSONB.valueOf(objectMapper.writeValueAsString(payload));
        } catch (Exception e) {
```

```java
package wqs.gen;

import java.math.BigDecimal;
import java.time.Instant;
import java.time.temporal.ChronoUnit;
import java.util.ArrayList;
import java.util.List;
import net.jqwik.api.Arbitraries;
import net.jqwik.api.Arbitrary;
import net.jqwik.api.Combinators;
import wqs.domain.ProjectionItem;
import wqs.domain.SourceKind;

/**
 * Generators shaped like production data (spec 8.1). Volumes are power-law: a small number of
 * users hold a disproportionate share of rows, and transactions cluster into sessions. Uniformly
 * random users would exercise none of that clustering.
 */
public final class EventGenerators {

    /** All generated timestamps sit inside one month so a single partition suffices. */
    public static final Instant WINDOW_START = Instant.parse("2034-03-01T00:00:00Z");
    public static final Instant WINDOW_END = Instant.parse("2034-03-31T23:00:00Z");

    /** Heavily skewed: user 1 appears far more often than user 20. */
    public static Arbitrary<Long> users() {
        return Arbitraries.frequency(
                net.jqwik.api.Tuple.of(50, 1L),
                net.jqwik.api.Tuple.of(20, 2L),
                net.jqwik.api.Tuple.of(10, 3L),
                net.jqwik.api.Tuple.of(5, 4L),
                net.jqwik.api.Tuple.of(1, 5L));
    }

    public static Arbitrary<SourceKind> sources() {
        return Arbitraries.of(
                SourceKind.TRANSACTION, SourceKind.TRANSACTION, SourceKind.TRANSACTION,
                SourceKind.CLAIMABLE_PRIZE, SourceKind.PAYMENT, SourceKind.MANUAL_ADJUSTMENT);
    }

    private static Arbitrary<Instant> timestamps() {
        long spanSeconds = ChronoUnit.SECONDS.between(WINDOW_START, WINDOW_END);
        return Arbitraries.longs().between(0, spanSeconds).map(WINDOW_START::plusSeconds);
    }

    private static Arbitrary<BigDecimal> amounts() {
        return Arbitraries.longs().between(-50_000, 50_000)
                .map(cents -> BigDecimal.valueOf(cents, 4));
    }

    /**
     * A sequence of items clustered into sessions: each session gets a batchId, a product, and
     * between 1 and 6 plays, each play 1 to 3 transactions.
     */
    public static Arbitrary<List<ProjectionItem>> itemSequences() {
        return Combinators.combine(
                        users(),
                        Arbitraries.integers().between(1, 4),   // sessions per user
                        Arbitraries.integers().between(1, 4),   // plays per session
                        Arbitraries.integers().between(1, 3),   // transactions per play
                        timestamps(),
                        amounts())
                .as(EventGenerators::buildSequence);
    }

    private static List<ProjectionItem> buildSequence(
            long userId, int sessions, int plays, int txPerPlay, Instant start, BigDecimal amount) {
        List<ProjectionItem> items = new ArrayList<>();
        int sequence = 0;

        for (int s = 0; s < sessions; s++) {
            String batchId = "u" + userId + "-s" + s;
            for (int p = 0; p < plays; p++) {
                String subBatchId = batchId + "-p" + p;
                for (int t = 0; t < txPerPlay; t++) {
                    items.add(new ProjectionItem(
                            userId,
                            SourceKind.TRANSACTION,
                            batchId + "-t" + (sequence++),
                            start.plusSeconds(sequence * 7L),
                            11,
                            batchId,
                            subBatchId,
                            (short) (t == 0 ? 1 : 2),
                            amount,
                            "EUR",
                            null,
                            null,
                            null));
                }
            }
        }

        // Unsessioned items: payments carry no batchId (spec 7.4).
        items.add(new ProjectionItem(
                userId, SourceKind.PAYMENT, "u" + userId + "-pay" + sequence,
                start.plusSeconds(sequence * 7L + 1), null, null, null,
                (short) 9, amount.abs(), "EUR", null, null, null));

        return items;
    }

    private EventGenerators() {}
}
```

```java
/**
 * Property P-1 (spec 8.1): applying any permutation or duplication of an event sequence
 * converges to identical projection state.
 *
 * Validates the locator idempotency gate. Phase 3 extends this to cancellations arriving on
 * either side of their originals.

@JqwikSpringSupport
@SpringBootTest
class IdempotencyPropertyTest extends PostgresTestBase {

    @DynamicPropertySource
    static void datasource(DynamicPropertyRegistry registry) {
        registry.add("spring.datasource.url", POSTGRES::getJdbcUrl);
        registry.add("spring.datasource.username", POSTGRES::getUsername);
        registry.add("spring.datasource.password", POSTGRES::getPassword);
    }

    @Autowired private ProjectionWriter writer;
    @Autowired private PartitionManager partitionManager;

    @BeforeTry
    void reset() {
        partitionManager.ensurePartitionsAhead(YearMonth.from(
                EventGenerators.WINDOW_START.atZone(java.time.ZoneOffset.UTC)), 1);
        dsl().execute("delete from \"wqItemLocator\"");
        dsl().execute("delete from \"wqWebItem\"");
        dsl().execute("delete from \"wqCcItem\"");
        dsl().execute("delete from \"wqStreamOffset\"");
    }

    @Property(tries = 40)
    void a_permuted_and_duplicated_sequence_converges_to_the_same_state(
            @ForAll("sequences") List<ProjectionItem> items,
            @ForAll long seed) {

        ProjectionSnapshot inOrder = applyAndSnapshot(items);

        reset();
        ProjectionSnapshot shuffledWithDuplicates = applyAndSnapshot(perturb(items, seed));

        assertThat(shuffledWithDuplicates).isEqualTo(inOrder);
    }

    @Property(tries = 20)
    void applying_a_sequence_twice_changes_nothing(
            @ForAll("sequences") List<ProjectionItem> items) {

        ProjectionSnapshot once = applyAndSnapshot(items);
        applyBatches(items);

        assertThat(ProjectionSnapshot.of(dsl())).isEqualTo(once);
    }

    @net.jqwik.api.Provide
    net.jqwik.api.Arbitrary<List<ProjectionItem>> sequences() {
        return EventGenerators.itemSequences();
    }

    private ProjectionSnapshot applyAndSnapshot(List<ProjectionItem> items) {
        applyBatches(items);
        return ProjectionSnapshot.of(dsl());
    }

    /** Applies in small batches, since batch boundaries are themselves a source of reordering. */
    private void applyBatches(List<ProjectionItem> items) {
        int batchSize = 3;
        for (int from = 0; from < items.size(); from += batchSize) {
            List<ProjectionItem> slice = items.subList(from, Math.min(from + batchSize, items.size()));
            writer.apply(new ProjectionBatch("wallet-transactions", slice, (long) from));
        }
    }

    /** Shuffles and duplicates roughly a third of the events. */
    private static List<ProjectionItem> perturb(List<ProjectionItem> items, long seed) {
        Random random = new Random(seed);
        List<ProjectionItem> perturbed = new ArrayList<>(items);
        for (ProjectionItem item : items) {
            if (random.nextInt(3) == 0) {
                perturbed.add(item);
            }
        }
        Collections.shuffle(perturbed, random);
        return perturbed;
    }
}
```

```java
package wqs.projection;

import java.math.BigDecimal;
import java.time.Instant;
import java.time.OffsetDateTime;
import java.time.ZoneOffset;
import java.util.Optional;
import org.jooq.DSLContext;
import org.springframework.stereotype.Component;
import wqs.domain.MoneyDirection;
import wqs.domain.ProjectionItem;

/**
 * Maintains session and play aggregates incrementally (spec 5.5). Only ever called for items the
 * locator gate accepted as new, so incrementing is safe -- a replayed event never reaches here.
 *
 * "totalPlays" is a monetary amount (the sum wagered), not a count. The count metric is
 * "playCount" on a session and "txCount" on a play.
 */
@Component
public class RollupUpdater {

    private static final String SESSION_MARKER = "";

    private final DSLContext dsl;

    public RollupUpdater(DSLContext dsl) {
        this.dsl = dsl;
    }

    public void applyItem(ProjectionItem item) {
        if (!item.isSessioned()) {
            return;
        }

        MoneyDirection direction = MoneyDirection.ofType(item.type());
        BigDecimal plays = direction == MoneyDirection.PLAY ? item.amount().abs() : BigDecimal.ZERO;
        BigDecimal wins = direction == MoneyDirection.WIN ? item.amount().abs() : BigDecimal.ZERO;

        boolean playIsNew = item.subBatchId() != null
                && upsertPlay(item, plays, wins);

        upsertSession(item, plays, wins, playIsNew);
    }

    /** @return true if this call created the play row. */
    private boolean upsertPlay(ProjectionItem item, BigDecimal plays, BigDecimal wins) {
        Optional<Instant> existing = locate(item.userId(), item.batchId(), item.subBatchId());
        Instant startedAt = existing.orElse(item.occurredAt());

        if (existing.isEmpty()) {
            recordLocation(item.userId(), item.batchId(), item.subBatchId(), startedAt);
        }

        dsl.execute("""
                    insert into "wqPlay" ("userId","batchId","subBatchId","startedAt","endedAt",
                                          "productId","currency","txCount","txCountExclCancelled",
                                          "totalPlays","totalWins","net",
                                          "totalPlaysExclCancelled","totalWinsExclCancelled",
                                          "netExclCancelled")
                    values (?,?,?,?,?,?,?,1,1,?,?,?,?,?,?)
                    on conflict ("userId","startedAt","batchId","subBatchId") do update set
                      "endedAt" = greatest("wqPlay"."endedAt", excluded."endedAt"),
                      "txCount" = "wqPlay"."txCount" + 1,
                      "txCountExclCancelled" = "wqPlay"."txCountExclCancelled" + 1,
                      "totalPlays" = "wqPlay"."totalPlays" + excluded."totalPlays",
                      "totalWins" = "wqPlay"."totalWins" + excluded."totalWins",
                      "net" = "wqPlay"."net" + excluded."net",
                      "totalPlaysExclCancelled" =
                          "wqPlay"."totalPlaysExclCancelled" + excluded."totalPlaysExclCancelled",
                      "totalWinsExclCancelled" =
                          "wqPlay"."totalWinsExclCancelled" + excluded."totalWinsExclCancelled",
                      "netExclCancelled" = "wqPlay"."netExclCancelled" + excluded."netExclCancelled"
                    """,
                item.userId(), item.batchId(), item.subBatchId(),
                at(startedAt), at(item.occurredAt()), item.productId(), item.currency(),
                plays, wins, wins.subtract(plays), plays, wins, wins.subtract(plays));

        return existing.isEmpty();
    }

    private void upsertSession(
            ProjectionItem item, BigDecimal plays, BigDecimal wins, boolean playIsNew) {
        Optional<Instant> existing = locate(item.userId(), item.batchId(), SESSION_MARKER);
        Instant startedAt = existing.orElse(item.occurredAt());

        if (existing.isEmpty()) {
            recordLocation(item.userId(), item.batchId(), SESSION_MARKER, startedAt);
        }

        int playDelta = playIsNew ? 1 : 0;

        dsl.execute("""
                    insert into "wqSession" ("userId","batchId","startedAt","endedAt",
                                             "productId","currency","txCount","txCountExclCancelled",
                                             "playCount","playCountExclCancelled",
                                             "totalPlays","totalWins","net",
                                             "totalPlaysExclCancelled","totalWinsExclCancelled",
                                             "netExclCancelled")
                    values (?,?,?,?,?,?,1,1,?,?,?,?,?,?,?,?)
                    on conflict ("userId","startedAt","batchId") do update set
                      "endedAt" = greatest("wqSession"."endedAt", excluded."endedAt"),
                      "txCount" = "wqSession"."txCount" + 1,
                      "txCountExclCancelled" = "wqSession"."txCountExclCancelled" + 1,
                      "playCount" = "wqSession"."playCount" + excluded."playCount",
                      "playCountExclCancelled" =
                          "wqSession"."playCountExclCancelled" + excluded."playCountExclCancelled",
                      "totalPlays" = "wqSession"."totalPlays" + excluded."totalPlays",
                      "totalWins" = "wqSession"."totalWins" + excluded."totalWins",
                      "net" = "wqSession"."net" + excluded."net",
                      "totalPlaysExclCancelled" =
                          "wqSession"."totalPlaysExclCancelled" + excluded."totalPlaysExclCancelled",
                      "totalWinsExclCancelled" =
                          "wqSession"."totalWinsExclCancelled" + excluded."totalWinsExclCancelled",
                      "netExclCancelled" =
                          "wqSession"."netExclCancelled" + excluded."netExclCancelled"
                    """,
                item.userId(), item.batchId(), at(startedAt), at(item.occurredAt()),
                item.productId(), item.currency(), playDelta, playDelta,
                plays, wins, wins.subtract(plays), plays, wins, wins.subtract(plays));
    }

    private Optional<Instant> locate(long userId, String batchId, String subBatchId) {
        return Optional.ofNullable(dsl.fetchOne("""
                        select "startedAt" from "wqGroupLocator"
                        where "userId" = ? and "batchId" = ? and "subBatchId" = ?
                        """, userId, batchId, subBatchId))
                .map(record -> record.get(0, Instant.class));
    }

    private void recordLocation(long userId, String batchId, String subBatchId, Instant startedAt) {
        dsl.execute("""
                    insert into "wqGroupLocator" ("userId","batchId","subBatchId","startedAt")
                    values (?,?,?,?) on conflict do nothing
                    """, userId, batchId, subBatchId, at(startedAt));
    }

    private static OffsetDateTime at(Instant instant) {
        return instant.atOffset(ZoneOffset.UTC);
    }
}
```

```java
package wqs.projection;

import java.time.OffsetDateTime;
import java.time.ZoneOffset;
import org.jooq.DSLContext;
import org.springframework.stereotype.Component;
import wqs.domain.ProjectionItem;
import wqs.domain.ViewKind;

/**
 * Maintains the level-1/2 page index (spec 5.6): exactly one row per session and one per
 * unsessioned item.
 *
 * A transaction joining an existing session inserts nothing, which is what keeps page counts
 * equal to the number of high-level items rather than the number of transactions.
 */
@Component
public class HighLevelUpdater {

    private static final short KIND_SESSION = 0;

    private final DSLContext dsl;

    public HighLevelUpdater(DSLContext dsl) {
        this.dsl = dsl;
    }

    /**
     * @param sessionIsNew whether this item just created its session row
     * @return number of page-index rows inserted
     */
    public int applyItem(ProjectionItem item, boolean sessionIsNew) {
        if (item.isSessioned() && !sessionIsNew) {
            return 0;
        }

        short kind = item.isSessioned() ? KIND_SESSION : (short) item.source().code();
        String refId = item.isSessioned() ? item.batchId() : item.sourceId();

        int inserted = 0;
        for (ViewKind view : item.source().views()) {
            inserted += insert(view, item, kind, refId);
        }
        return inserted;
    }

    private int insert(ViewKind view, ProjectionItem item, short kind, String refId) {
        String table = view == ViewKind.WEB ? "wqWebHighLevel" : "wqCcHighLevel";
        return dsl.execute("""
                           insert into "%s" ("userId","occurredAt","kind","refId","productId",
                                             "currency","visibleExclCancelled")
                           values (?,?,?,?,?,?,true)
                           on conflict do nothing
                           """.formatted(table),
                item.userId(),
                item.occurredAt().atOffset(ZoneOffset.UTC),
                kind,
                refId,
                item.productId(),
                item.currency());
    }

    private static OffsetDateTime at(java.time.Instant instant) {
        return instant.atOffset(ZoneOffset.UTC);
    }
}
```

```java
package wqs.projection;

import java.time.Instant;
import java.time.LocalDate;
import java.time.ZoneOffset;
import org.jooq.DSLContext;
import org.springframework.stereotype.Component;
import wqs.domain.PageUnit;
import wqs.domain.ProjectionItem;
import wqs.domain.ViewKind;

/**
 * Maintains the two-tier pagination counters (spec 5.7).
 *
 * productId = 0 is the all-products sentinel, so the common unfiltered query reads one row
 * rather than summing across products. An item therefore increments two rows per view: its own
 * product and the sentinel. An item with no product increments the sentinel only.
 */
@Component
public class CounterUpdater {

    private static final int ALL_PRODUCTS = 0;

    private final DSLContext dsl;

    public CounterUpdater(DSLContext dsl) {
        this.dsl = dsl;
    }

    /** Counts one level-0 row in each view this item's source feeds. */
    public void countItem(ProjectionItem item) {
        for (ViewKind view : item.source().views()) {
            increment(item.userId(), view, PageUnit.ITEM, item.productId(), item.occurredAt());
        }
    }

    /** Counts one level-1/2 page unit. Called only when a high-level row was actually inserted. */
    public void countHighLevel(ProjectionItem item) {
        for (ViewKind view : item.source().views()) {
            increment(item.userId(), view, PageUnit.HIGH_LEVEL, item.productId(), item.occurredAt());
        }
    }

    /**
     * Removes one row from the excl-cancelled tally, leaving cntAll untouched: a cancelled item
     * still exists and is still returned when the filter is off.
     */
    public void uncountExclCancelled(
            long userId, ViewKind view, PageUnit unit, Integer productId, Instant at) {
        LocalDate day = LocalDate.ofInstant(at, ZoneOffset.UTC);
        for (Integer product : productKeys(productId)) {
            decrementOne("wqCountDay", userId, view, unit, product, day);
            decrementOne("wqCountMonth", userId, view, unit, product, day.withDayOfMonth(1));
        }
    }

    private void increment(
            long userId, ViewKind view, PageUnit unit, Integer productId, Instant at) {
        LocalDate day = LocalDate.ofInstant(at, ZoneOffset.UTC);
        for (Integer product : productKeys(productId)) {
            incrementOne("wqCountDay", userId, view, unit, product, day);
            incrementOne("wqCountMonth", userId, view, unit, product, day.withDayOfMonth(1));
        }
    }

    /** Its own product (when it has one), plus the all-products sentinel. */
    private static Integer[] productKeys(Integer productId) {
        return productId == null
                ? new Integer[] {ALL_PRODUCTS}
                : new Integer[] {productId, ALL_PRODUCTS};
    }

    private void incrementOne(
            String table, long userId, ViewKind view, PageUnit unit, int productId, LocalDate period) {
        dsl.execute("""
                    insert into "%s" ("userId","viewKind","pageUnit","productId","period",
                                      "cntAll","cntExclCancelled")
                    values (?,?,?,?,?,1,1)
                    on conflict ("userId","viewKind","pageUnit","productId","period") do update set
                      "cntAll" = "%s"."cntAll" + 1,
                      "cntExclCancelled" = "%s"."cntExclCancelled" + 1
                    """.formatted(table, table, table),
                userId, (short) view.code(), unit.code(), productId, period);
    }

    private void decrementOne(
            String table, long userId, ViewKind view, PageUnit unit, int productId, LocalDate period) {
        dsl.execute("""
                    update "%s" set "cntExclCancelled" = greatest("cntExclCancelled" - 1, 0)
                    where "userId" = ? and "viewKind" = ? and "pageUnit" = ?
                      and "productId" = ? and "period" = ?
                    """.formatted(table),
                userId, (short) view.code(), unit.code(), productId, period);
    }
}
```

```java
package wqs.projection;

import org.springframework.stereotype.Component;
import org.springframework.transaction.annotation.Transactional;
import wqs.domain.ProjectionItem;
import wqs.ingest.stream.StreamOffsetStore;

/**
 * The single write choke point (spec section 6). Implements the ordering in spec 6.2:
 * normalize, gate, insert, rollups, page index, counters, then the offset -- all in one
 * transaction, so projection state and consumer position advance or roll back together.
 */
@Component
public class ProjectionWriter {

    private final ItemInserter itemInserter;
    private final RollupUpdater rollupUpdater;
    private final HighLevelUpdater highLevelUpdater;
    private final CounterUpdater counterUpdater;
    private final StreamOffsetStore offsetStore;

    public ProjectionWriter(
            ItemInserter itemInserter,
            RollupUpdater rollupUpdater,
            HighLevelUpdater highLevelUpdater,
            CounterUpdater counterUpdater,
            StreamOffsetStore offsetStore) {
        this.itemInserter = itemInserter;
        this.rollupUpdater = rollupUpdater;
        this.highLevelUpdater = highLevelUpdater;
        this.counterUpdater = counterUpdater;
        this.offsetStore = offsetStore;
    }

    @Transactional
    public WriteResult apply(ProjectionBatch batch) {
        int projected = 0;
        int duplicates = 0;

        for (ProjectionItem item : batch.items()) {
            // The gate makes everything below safe to do incrementally: a replayed event
            // never reaches it, so no counter or aggregate is ever applied twice.
            if (!itemInserter.insertIfAbsent(item)) {
                duplicates++;
                continue;
            }
            projected++;

            RollupResult rollup = rollupUpdater.applyItem(item);

            int pageRows = highLevelUpdater.applyItem(item, rollup.sessionIsNew());

            counterUpdater.countItem(item);
            if (pageRows > 0) {
                counterUpdater.countHighLevel(item);
            }
        }

        if (batch.committedOffset() != null) {
            offsetStore.write(batch.stream(), batch.committedOffset());
        }

        return new WriteResult(projected, duplicates);
    }
}
```

```java
package wqs.projection;

import java.math.BigDecimal;
import java.time.Instant;
import java.time.ZoneOffset;
import org.jooq.DSLContext;
import org.jooq.Record;
import org.springframework.stereotype.Component;
import wqs.domain.MoneyDirection;
import wqs.domain.PageUnit;
import wqs.domain.ProjectionItem;
import wqs.domain.SourceKind;
import wqs.domain.ViewKind;

/**
 * Applies a cancellation to an already-projected item (spec 6.3).
 *
 * The rule worth reading twice: a session belongs in the excl-cancelled total while it retains at
 * least one non-cancelled transaction. So the ITEM tally always decrements, but the HIGH_LEVEL
 * tally decrements only when "visibleExclCancelled" flips true -> false. The same shape applies
 * one level down to "playCountExclCancelled".
 */
@Component
public class CancellationApplier {

    private final DSLContext dsl;
    private final CounterUpdater counterUpdater;
    private final PendingCancelStore pendingCancelStore;

    public CancellationApplier(
            DSLContext dsl, CounterUpdater counterUpdater, PendingCancelStore pendingCancelStore) {
        this.dsl = dsl;
        this.counterUpdater = counterUpdater;
        this.pendingCancelStore = pendingCancelStore;
    }

    /** @return true if applied; false if the target is unknown and the cancel was parked. */
    public boolean apply(ProjectionItem cancel) {
        Record original = findOriginal(cancel.cancels());
        if (original == null) {
            pendingCancelStore.park(cancel);
            return false;
        }

        // Already cancelled: do nothing, so a replayed cancel cannot double-decrement.
        if (Boolean.TRUE.equals(original.get("cancelled", Boolean.class))) {
            return true;
        }

        long userId = original.get("userId", Long.class);
        Instant occurredAt = original.get("occurredAt", Instant.class);
        Integer productId = original.get("productId", Integer.class);
        String batchId = original.get("batchId", String.class);
        String subBatchId = original.get("subBatchId", String.class);
        short sourceCode = original.get("source", Short.class);
        SourceKind source = SourceKind.ofCode(sourceCode);

        // Subtract the ORIGINAL item's own contribution. Zeroing the excl-cancelled totals
        // instead would be wrong for any play holding more than one transaction.
        MoneyDirection direction = MoneyDirection.ofType(original.get("type", Short.class));
        BigDecimal amount = original.get("amount", BigDecimal.class).abs();
        BigDecimal plays = direction == MoneyDirection.PLAY ? amount : BigDecimal.ZERO;
        BigDecimal wins = direction == MoneyDirection.WIN ? amount : BigDecimal.ZERO;

        markCancelled(cancel, source, occurredAt);

        for (ViewKind view : source.views()) {
            counterUpdater.uncountExclCancelled(userId, view, PageUnit.ITEM, productId, occurredAt);
        }

        if (batchId == null) {
            hideHighLevelRow(source, userId, occurredAt, cancel.cancels(), productId,
                    (short) source.code());
            return true;
        }

        boolean playEmptied = decrementPlay(userId, batchId, subBatchId, plays, wins);
        boolean sessionEmptied = decrementSession(userId, batchId, playEmptied, plays, wins);

        if (sessionEmptied) {
            Instant sessionStart = sessionStartedAt(userId, batchId);
            hideHighLevelRow(source, userId, sessionStart, batchId, productId, (short) 0);
        }
        return true;
    }

    private Record findOriginal(String sourceId) {
        Record locator = dsl.fetchOne("""
                select "userId","occurredAt" from "wqItemLocator" where "sourceId" = ?
                """, sourceId);
        if (locator == null) {
            return null;
        }
        // "wqCcItem" carries all five sources, so it is always the right place to read from.
        return dsl.fetchOne("""
                select "userId","occurredAt","productId","batchId","subBatchId","source",
                       "cancelled","type","amount"
                from "wqCcItem"
                where "userId" = ? and "occurredAt" = ? and "sourceId" = ?
                """,
                locator.get("userId", Long.class),
                locator.get("occurredAt", Instant.class).atOffset(ZoneOffset.UTC),
                sourceId);
    }

    private void markCancelled(ProjectionItem cancel, SourceKind source, Instant occurredAt) {
        for (ViewKind view : source.views()) {
            dsl.execute("""
                        update "%s" set "cancelled" = true, "cancelledBy" = ?
                        where "sourceId" = ? and "occurredAt" = ?
                        """.formatted(view.itemTable()),
                    cancel.sourceId(), cancel.cancels(), occurredAt.atOffset(ZoneOffset.UTC));
        }
    }

    /** @return true if the play has no surviving transactions left. */
    private boolean decrementPlay(
            long userId, String batchId, String subBatchId, BigDecimal plays, BigDecimal wins) {
        if (subBatchId == null) {
            return false;
        }
        Record updated = dsl.fetchOne("""
                update "wqPlay" set
                  "txCountExclCancelled" = greatest("txCountExclCancelled" - 1, 0),
                  "totalPlaysExclCancelled" = "totalPlaysExclCancelled" - ?,
                  "totalWinsExclCancelled" = "totalWinsExclCancelled" - ?,
                  "netExclCancelled" = "netExclCancelled" - (? - ?)
                where "userId" = ? and "batchId" = ? and "subBatchId" = ?
                returning "txCountExclCancelled"
                """, plays, wins, wins, plays, userId, batchId, subBatchId);
        return updated != null && updated.get(0, Integer.class) == 0;
    }

    /** @return true if the session has no surviving transactions left. */
    private boolean decrementSession(
            long userId, String batchId, boolean playEmptied, BigDecimal plays, BigDecimal wins) {
        Record updated = dsl.fetchOne("""
                update "wqSession" set
                  "txCountExclCancelled" = greatest("txCountExclCancelled" - 1, 0),
                  "playCountExclCancelled" = greatest("playCountExclCancelled" - ?, 0),
                  "totalPlaysExclCancelled" = "totalPlaysExclCancelled" - ?,
                  "totalWinsExclCancelled" = "totalWinsExclCancelled" - ?,
                  "netExclCancelled" = "netExclCancelled" - (? - ?)
                where "userId" = ? and "batchId" = ?
                returning "txCountExclCancelled"
                """, playEmptied ? 1 : 0, plays, wins, wins, plays, userId, batchId);
        return updated != null && updated.get(0, Integer.class) == 0;
    }

    private Instant sessionStartedAt(long userId, String batchId) {
        return dsl.fetchOne("""
                select "startedAt" from "wqGroupLocator"
                where "userId" = ? and "batchId" = ? and "subBatchId" = ''
                """, userId, batchId).get(0, Instant.class);
    }

    private void hideHighLevelRow(
            SourceKind source, long userId, Instant occurredAt, String refId,
            Integer productId, short kind) {
        for (ViewKind view : source.views()) {
            String table = view == ViewKind.WEB ? "wqWebHighLevel" : "wqCcHighLevel";
            int updated = dsl.execute("""
                        update "%s" set "visibleExclCancelled" = false
                        where "userId" = ? and "occurredAt" = ? and "kind" = ? and "refId" = ?
                          and "visibleExclCancelled"
                        """.formatted(table),
                    userId, occurredAt.atOffset(ZoneOffset.UTC), kind, refId);

            // Only decrement when the flag actually flipped -- that is the whole rule.
            if (updated > 0) {
                counterUpdater.uncountExclCancelled(
                        userId, view, PageUnit.HIGH_LEVEL, productId, occurredAt);
            }
        }
    }
}
```

```java
package wqs.projection;

import java.util.List;
import org.jooq.DSLContext;
import org.jooq.Record;

/**
 * Oracle queries for the three projection invariants. Each returns discrepancies, empty when the
 * invariant holds.
 *
 * Intentionally written as slow-but-obvious SQL: these are the reference implementations the fast
 * paths are checked against. Phase 7's reconciliation jobs reuse them against production data.
 */
public final class ProjectionInvariants {

    private final DSLContext dsl;

    public ProjectionInvariants(DSLContext dsl) {
        this.dsl = dsl;
    }

    /** P-2: every stored counter equals an actual COUNT over the projection. */
    public List<String> counterDrift() {
        return dsl.fetch("""
                with actual as (
                    select "userId", 1 as "viewKind", 0 as "pageUnit", 0 as "productId",
                           ("occurredAt" at time zone 'UTC')::date as "period",
                           count(*) as "cntAll",
                           count(*) filter (where not "cancelled") as "cntExcl"
                    from "wqWebItem" group by 1,5
                  union all
                    select "userId", 2, 0, 0, ("occurredAt" at time zone 'UTC')::date,
                           count(*), count(*) filter (where not "cancelled")
                    from "wqCcItem" group by 1,5
                  union all
                    select "userId", 1, 1, 0, ("occurredAt" at time zone 'UTC')::date,
                           count(*), count(*) filter (where "visibleExclCancelled")
                    from "wqWebHighLevel" group by 1,5
                  union all
                    select "userId", 2, 1, 0, ("occurredAt" at time zone 'UTC')::date,
                           count(*), count(*) filter (where "visibleExclCancelled")
                    from "wqCcHighLevel" group by 1,5
                )
                select a."userId", a."viewKind", a."pageUnit", a."period",
                       a."cntAll" as "expectedAll", coalesce(c."cntAll", 0) as "storedAll",
                       a."cntExcl" as "expectedExcl",
                       coalesce(c."cntExclCancelled", 0) as "storedExcl"
                from actual a
                left join "wqCountDay" c
                  on c."userId" = a."userId" and c."viewKind" = a."viewKind"
                 and c."pageUnit" = a."pageUnit" and c."productId" = 0
                 and c."period" = a."period"
                where a."cntAll" <> coalesce(c."cntAll", 0)
                   or a."cntExcl" <> coalesce(c."cntExclCancelled", 0)
                """)
                .map(Record::toString);
    }

    /** P-4: session values equal the sum of their plays, and net equals wins minus plays. */
    public List<String> aggregationDrift() {
        return dsl.fetch("""
                with play_totals as (
                    select "userId", "batchId",
                           sum("totalPlays") as "plays", sum("totalWins") as "wins",
                           sum("txCount") as "txCount", count(*) as "playCount"
                    from "wqPlay" group by 1,2
                )
                select s."userId", s."batchId",
                       s."totalPlays", p."plays", s."totalWins", p."wins",
                       s."txCount", p."txCount", s."playCount", p."playCount", s."net"
                from "wqSession" s
                join play_totals p on p."userId" = s."userId" and p."batchId" = s."batchId"
                where s."totalPlays" <> p."plays"
                   or s."totalWins" <> p."wins"
                   or s."txCount" <> p."txCount"
                   or s."playCount" <> p."playCount"
                   or s."net" <> s."totalWins" - s."totalPlays"
                """)
                .map(Record::toString);
    }

    /**
     * P-8: the high-level index holds exactly one row per session plus one per unsessioned item,
     * and "visibleExclCancelled" agrees with the underlying rows.
     */
    public List<String> highLevelDrift() {
        return dsl.fetch("""
                with expected as (
                    select "userId", "startedAt" as "occurredAt", 0 as "kind", "batchId" as "refId",
                           ("txCountExclCancelled" > 0) as "visible"
                    from "wqSession"
                  union all
                    select "userId", "occurredAt", "source", "sourceId", not "cancelled"
                    from "wqCcItem" where "batchId" is null
                )
                select coalesce(e."refId", h."refId") as "refId",
                       e."visible" as "expectedVisible", h."visibleExclCancelled" as "storedVisible",
                       case when e."refId" is null then 'orphan row'
                            when h."refId" is null then 'missing row'
                            else 'visibility mismatch' end as "problem"
                from expected e
                full outer join "wqCcHighLevel" h
                  on h."userId" = e."userId" and h."occurredAt" = e."occurredAt"
                 and h."kind" = e."kind" and h."refId" = e."refId"
                where e."refId" is null
                   or h."refId" is null
                   or e."visible" <> h."visibleExclCancelled"
                """)
                .map(Record::toString);
    }
}
```

```java
        TABLES.forEach(table -> dsl().execute("delete from \"" + table + "\""));
    }

    /** Small batches, since batch boundaries are themselves a source of reordering. */
    protected void applyBatches(List<ProjectionItem> items) {
        int batchSize = 3;
        for (int from = 0; from < items.size(); from += batchSize) {
            List<ProjectionItem> slice =
                    items.subList(from, Math.min(from + batchSize, items.size()));
            writer.apply(new ProjectionBatch("wallet-transactions", slice, (long) from));
        }
    }
}
```
